# Pharma AI Agent

A beginner-friendly AI assistant for pharmaceutical learning, built with Python and Google's Gemini API.

## Features

- Explains GMP, QA, QMS, CAPA, deviations, and data integrity
- Provides answers in simple Hinglish when appropriate
- Supports multiple questions in one session

## Requirements

- Python 3.10 or later
- A Google Gemini API key
- Internet connection

## Installation

Install the required library:

```bash
pip install -r requirements.txt
```

## Run the assistant

```bash
python app.py
```

Enter your Gemini API key when prompted. Ask a pharmaceutical question, or type `exit` to end the session.

## Security

Never commit your API key to GitHub or share it publicly.
